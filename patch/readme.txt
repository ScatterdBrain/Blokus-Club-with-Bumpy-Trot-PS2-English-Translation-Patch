An English translation patch for Irem's PS2 game Blokus Club with Bumpy Trot [SLPS-20443].

Patch file was created with Delta Patcher 3.1.5 and was tested with MD5: 37f2d3ecbbd4b15cc1af52379a99b66d copy of the game.

Don't forget to make a backup of your game before patching!

If you experience any issues with the patch or notice any mistakes you can create an issue on GitHub https://github.com/ScatterdBrain/Blokus-Club-with-Bumpy-Trot-PS2-English-Translation-Patch
